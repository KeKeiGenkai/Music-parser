# Веб-интерфейс Spotify Recorder

Открой сайт в браузере, вставь ссылку на трек или плейлист — треки записываются и доступны для скачивания.

## Запуск

**Docker (рекомендуется):**
```bash
docker compose -f docker-compose.web.yml up -d --build
```
Открой http://localhost:8080

**Локально (требуется WSL/Linux для записи):**
```bash
python -m uvicorn web:app --host 127.0.0.1 --port 8080
```

## Использование

1. **Запись по ссылке** — вставь URL трека или плейлиста Spotify, нажми «Записать».
2. **При 403** — если API недоступен (гео-ограничения в Docker):
   - На хосте выполни: `python run_record.py --fetch-playlist "URL"`
   - В веб-интерфейсе открой блок «При 403», выбери плейлист из списка, нажми «Записать».
3. **Скачивание** — в разделе «Записи» нажми «Скачать» у нужного трека.

## Требования

- Один раз выполнить OAuth на хосте: `python run_record.py --auth`
- Кэш Spotipy и librespot должен быть в `.recorder_cache/` (примонтирован в Docker)
